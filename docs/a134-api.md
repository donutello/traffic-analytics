# Документация API и модулей: Сервис анализа трафика (Трасса А-134)

Документация содержит описание серверного эндпоинта и внутренних Python-функций для парсинга и выявления суточных/месячных аномалий в отчетах интенсивности движения.

---

## 📌 Серверное API

### Эндпоинт: Анализ Excel-отчетов
**`POST /api/v1/traffic/analyze`**

Принимает Excel-файлы с отчетами, парсит их, выявляет суточные/месячные аномалии и генерирует графики.

#### 📥 Параметры запроса (Multipart / Form-Data)

| Параметр | Тип | Обязательный | Описание |
| :--- | :--- | :---: | :--- |
| **`files`** | `array (binary)` | **Да** | Список файлов `.xlsx` или `.xls` для анализа (формат трассы А-134). |

#### 📤 Успешный ответ (Response 200 JSON)

| Код | Описание |
| :---: | :--- |
| **400** | **Ошибка валидации:** файлы повреждены, пустые или имеют неверный формат столбцов. |
| **500** | **Внутренняя ошибка сервера** при расчете статистических метрик или отрисовке графиков. |

## 🐍 Python Модули

### 1. Функция `parse_traffic_excel`
Потоковый парсер для файла А-134. Находит участок трассы, распознает даты, очищает текстовые аномалии и преобразует данные в числовой формат.

#### Сигнатура
```python
def parse_traffic_excel(filepath: str) -> pd.DataFrame:
```

#### 📥 Параметры функции

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| **`filepath`** | `str` | **Да** | Абсолютный или относительный путь к файлу Excel на диске. |

#### 📤 Возвращаемое значение (`pd.DataFrame`)

| Поле DataFrame | Тип | Описание |
| :--- | :---: | :--- |
| **`road_section`** | `string` | Распознанное название или километр участка дороги. |
| **`timestamp`** | `datetime64` | Дата и час замера. |
| **`vol_total`** / **`_direct`** / **`_reverse`** | `int` / `float` | Общая интенсивность, по прямому и обратному направлению. |
| **`cars_...`** / **`small_trucks_...`** / **`med_trucks_...`** / **`large_trucks_...`** / **`road_trains_...`** / **`buses_...`** / **`motos_...`** | `int` / `float` | Разделение интенсивности по типам транспортных средств. |
| **`speed_direct`** / **`_reverse`** | `float` | Средняя скорость движения по направлениям (км/ч). |
| **`load_direct`** / **`_reverse`** | `float` | Уровень загрузки дороги по направлениям (%). |

#### ⚠️ Исключения (Exceptions)

| Исключение | Условие возникновения |
| :--- | :--- |
| **`FileNotFoundError`** | Указанный файл отсутствует по заданному пути `filepath`. |
| **`zipfile.BadZipFile`** | Файл поврежден и не может быть открыт библиотекой `openpyxl`. |

### 2. Функция `detect_daily_anomalies`
Поиск аномалий на суточном уровне (неполные сутки, flatline датчика, дисбаланс направлений, заторы, искажение профиля и амплитудные всплески/спады).

#### Сигнатура
```python
def detect_daily_anomalies(df: pd.DataFrame) -> pd.DataFrame:
```

#### 📥 Параметры функции

| Параметр | Тип | Обязательный | Описание |
| :--- | :---: | :---: | :--- |
| **`df`** | `pd.DataFrame` | **Да** | Очищенный датафрейм, полученный из функции `parse_traffic_excel`. |

#### 📤 Возвращаемое значение (`pd.DataFrame`)

| Поле DataFrame | Тип | Описание |
| :--- | :---: | :--- |
| **`Участок дороги`** | `string` | Название участка трассы. |
| **`Дата`** | `date` | Дата обнаружения инцидента. |
| **`Уровень`** | `string` | Критичность (Критический или Высокий). |
| **`Детектор`** | `string` | Имя алгоритма (например, Датчик, Амплитуда, Направление). |
| **`Тип аномалии`** | `string` | Развернутое название проблемы (например, Залипание датчика (Flatline)). |
| **`Параметр`** | `string` | Метрика, на которой произошел сбой. |
| **`Факт`** | `any` | Фактическое аномальное значение. |
| **`Норма`** | `any` | Ожидаемое значение или диапазон по норме. |
| **`Отклонение (%)`** | `float` | Процент отклонения от нормы. |
| **`Индекс (Score)`** | `float` | Статистический вес аномалии (метрика Z-score или жесткий приоритет). |
| **`Описание цифрами`** | `string` | Понятный текст для отображения на фронтенде. |
