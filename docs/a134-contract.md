## 📊 Контракты для интеграции с Дашбордом (Frontend)

### 1. Получение агрегированных метрик (Виджеты / KPI)
**`GET /api/v1/dashboard/summary`**

Возвращает верхнеуровневую статистику для карточек KPI на дашборде за указанный период.

#### 📥 Query-параметры

| Параметр | Тип | Обязательный | Описание | Пример |
| :--- | :---: | :---: | :--- | :--- |
| **`start_date`** | `string (date)` | Нет | Начало периода анализа (ISO 8601) | `2026-10-01` |
| **`end_date`** | `string (date)` | Нет | Конец периода анализа (ISO 8601) | `2026-10-31` |
| **`road_section`** | `string` | Нет | Фильтр по конкретному участку дороги | `км 4+000` |

#### 📤 Успешный ответ (Response 200 JSON)

```json
{
  "period": {
    "start_date": "2026-10-01",
    "end_date": "2026-10-31"
  },
  "kpi": {
    "total_records_processed": 144000,
    "active_detectors_count": 8,
    "critical_anomalies_total": 14,
    "high_anomalies_total": 42
  },
  "status_distribution": {
    "normal_hours_pct": 96.1,
    "anomaly_hours_pct": 3.9
  },
  "top_anomalous_sections": [
    {
      "road_section": "км 4+000 подъезд к г. Воронеж",
      "anomalies_count": 18
    },
    {
      "road_section": "км 12+300 а/д А-134",
      "anomalies_count": 5
    }
  ]
}
```

### 2. Получение отфильтрованного списка суточных аномалий (Таблица инцидентов)
**`GET /api/v1/dashboard/daily-anomalies`**

Возвращает список зафиксированных суточных аномалий с поддержкой серверной фильтрации и пагинации.

#### 📥 Query-параметры

| Параметр | Тип | Обязательный | Описание | Пример |
| :--- | :---: | :---: | :--- | :--- |
| **`page`** | `int` | Нет | Номер страницы (дефолт: `1`) | `1` |
| **`limit`** | `int` | Нет | Количество элементов на странице (дефолт: `20`) | `50` |
| **`level`** | `string` | Нет | Фильтр по критичности (`Критический`, `Высокий`) | `Критический` |
| **`detector`** | `string` | Нет | Фильтр по типу алгоритма / датчика | `Скорость/Загрузка` |
| **`road_section`** | `string` | Нет | Поиск по названию/километру участка | `Воронеж` |

#### 📤 Успешный ответ (Response 200 JSON)

```json
{
  "pagination": {
    "total_items": 124,
    "page": 1,
    "limit": 50,
    "pages_count": 3
  },
  "items": [
    {
      "id": "anom_daily_98241",
      "road_section": "км 4+000 подъезд к г. Воронеж",
      "date": "2026-10-17",
      "level": "Критический",
      "detector": "Скорость/Загрузка",
      "anomaly_type": "Экстремальный затор",
      "parameter": "Мин. скорость (Прямое)",
      "fact": 45.5,
      "norm": "> 70 км/ч",
      "deviation_pct": -43.1,
      "score": 4.5,
      "description": "В 18:00 скорость упала до 45.5 км/ч при загрузке 22%",
      "plot_url": "/api/v1/plots/2026-10-17_km_4_000.png"
    }
  ]
}
```

### 3. Данные для временных рядов (Графики / Charts)
**`GET /api/v1/dashboard/traffic-timeline`**

Возвращает исторические данные интенсивности и скорости по часам для построения графиков (Line Charts) на фронтенде.

#### 📥 Query-параметры

| Параметр | Тип | Обязательный | Описание | Пример |
| :--- | :---: | :---: | :--- | :--- |
| **`road_section`** | `string` | **Да** | Точное название участка для детализации | `км 4+000 подъезд к г. Воронеж` |
| **`start_date`** | `string (date)` | **Да** | Начало временного диапазона | `2026-10-10` |
| **`end_date`** | `string (date)` | **Да** | Конец временного диапазона | `2026-10-17` |

#### 📤 Успешный ответ (Response 200 JSON)

```json
{
  "road_section": "км 4+000 подъезд к г. Воронеж",
  "metrics": [
    {
      "timestamp": "2026-10-17T17:00:00Z",
      "vol_total": 1250,
      "speed_direct": 72.4,
      "load_direct": 15.2,
      "is_anomaly": false
    },
    {
      "timestamp": "2026-10-17T18:00:00Z",
      "vol_total": 1890,
      "speed_direct": 45.5,
      "load_direct": 22.0,
      "is_anomaly": true,
      "anomaly_id": "anom_daily_98241"
    }
  ]
}
```
